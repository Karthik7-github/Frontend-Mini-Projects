# 🎬 Movie Search App

A simple and interactive **Movie Search Web App** built using **HTML, CSS, and JavaScript**. This application allows users to search for any movie and view its details such as poster, title, and other information using a Movie API.

---

## 🚀 Features

* 🔍 Search for any movie by name
* 🎥 Displays movie poster dynamically
* 📄 Shows movie details (title, info, etc.)
* ⚡ Fast and responsive UI
* 🧠 Uses Movie API for real-time data

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Movie API (e.g., OMDb API or similar)

## ⚙️ How It Works

1. User enters a movie name in the search bar
2. Clicks the **Search** button
3. JavaScript fetches data from the Movie API
4. Movie details are displayed dynamically:

   * Poster
   * Title
   * Additional information

   ```bash

   ```

## 🔑 API Setup

* Get your API key from a Movie API (like OMDb API)
* Add your API key inside `script.js`:

