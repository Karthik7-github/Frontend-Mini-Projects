# ☕ Coffee Shop Website

A modern and responsive Coffee Shop website built using **HTML, CSS, and JavaScript**. This project showcases a stylish UI with sections like Home, About, Menu, Testimonials, Gallery, and Contact.

---

## 🚀 Features

* 🏠 Hero section with call-to-action buttons
* 📖 About section with social media links
* 🍽️ Menu section displaying items with images
* 💬 Testimonials slider using Swiper.js
* 🖼️ Image gallery
* 📞 Contact section with form and details
* 📱 Fully responsive design
* 🎨 Font Awesome icons integration

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Swiper.js (for testimonials slider)
* Font Awesome (for icons)

   ```bash
   cd coffee-shop
   ```
